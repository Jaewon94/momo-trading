# 이벤트 레이더 고도화 스펙

## 목표

관리자 화면에서 실시간 이벤트를 단순 활동 로그가 아니라 `지금 확인할 가치가 있는 운영 신호`로 보여준다.

핵심은 다음 네 가지다.

- 이벤트를 `트리거`와 `확인`으로 구분한다.
- 이벤트 강도를 점수로 보여준다.
- 같은 이벤트가 왜 다시 안 뜨는지 `쿨다운` 상태를 보여준다.
- 종목 상세 모달과 연결해 현재 보유 종목 의사결정 맥락을 이어준다.

## 현재 문제

- 활동 로그는 이력이 잘 남지만 우선순위가 약하다.
- 급등/급락/거래량 이벤트가 `언제 들어왔는지`는 보이지만 `얼마나 중요한지`는 안 보인다.
- 이벤트 dedup이 내부적으로만 동작하고 UI에는 드러나지 않는다.
- 종목 상세 모달에서 최근 이벤트와 거래/AI 타임라인이 분리돼 있다.

## 사용자 가치

운영자는 관리자 화면을 열자마자 다음을 3초 안에 이해해야 한다.

- 지금 강한 이벤트가 몇 개인지
- 바로 볼 종목이 무엇인지
- 매수/매도 후보가 무엇인지
- 같은 종목이 왜 다시 분석되지 않는지

## 화면 원칙

### 1. 레이더는 활동 로그 위에 있는 운영 요약 레이어다

- 활동 로그를 대체하지 않는다.
- 활동 로그는 상세 이력
- 이벤트 레이더는 현재 우선순위

### 2. 상태는 색과 레이블이 동시에 보여야 한다

- 색만으로 의미를 전달하지 않는다.
- `TRIGGERED`, `CONFIRMED`, `ACTIONABLE`, `COOLDOWN`처럼 텍스트를 같이 쓴다.

### 3. 숫자는 해석 가능한 형태로 보여야 한다

- 점수는 `82점`
- 쿨다운은 `45초 남음`
- 변화율은 `+5.31%`
- 거래량은 `3.8배`

## 제안 UI

### 메인 패널 상단: Event Radar

- 상단 요약 바
  - `실시간 이벤트 N`
  - `확인 대기 N`
  - `즉시 액션 후보 N`
  - `쿨다운 N`
- 필터 칩
  - `전체`
  - `매수 후보`
  - `매도 후보`
  - `쿨다운`
  - `오류`
- 레이더 카드 리스트
  - 왼쪽: 이벤트 타입 배지
  - 중앙: 회사명, 심볼, 이벤트 제목
  - 오른쪽: 점수, 상태, 시각

### 종목 상세 모달 상단: Recent Events Strip

- 최근 이벤트 3건 정도를 요약 칩으로 보여준다.
- 예:
  - `익절 임박`
  - `거래량 4.2배`
  - `쿨다운 30초`

## 상태 모델

### 이벤트 상태

- `TRIGGERED`
  - 기준을 넘긴 직후
- `CONFIRMED`
  - 확인 조건을 만족
- `ACTIONABLE`
  - 실제 매수/매도 해석에 쓸 가치가 있음
- `COOLDOWN`
  - 같은 타입 재발행 방지 구간
- `EXECUTED`
  - 실제 주문 또는 후속 처리로 이어짐
- `DISMISSED`
  - 노이즈로 판단되거나 후순위 처리됨

이번 구현 범위는 `TRIGGERED`, `ACTIONABLE`, `COOLDOWN`까지를 우선 지원한다.

## 점수 모델 v1

점수는 0~100 범위 정수로 만든다.

### 가격 급등/급락

- 기준 초과 폭
- 현재 변화율 절대값
- 보유 종목 여부
- 손절/익절과의 거리

### 거래량 급증

- 현재 거래량 / 최근 평균 거래량
- 최근 가격 움직임 동반 여부
- 보유 종목 여부

### 손절/익절 도달

- 기본 점수 상향
- 보유 종목이면 우선순위 상향
- 트레일링 스탑 기반이면 보조 문구 추가

## 데이터 소스

이번 버전은 영속 저장 대신 `event_detector`의 메모리 상태를 사용한다.

- 최근 이벤트 목록
- 종목별 마지막 이벤트
- 이벤트 강도 점수
- 마지막 감지 시각
- 쿨다운 종료 시각

## API 설계

신규 엔드포인트:

- `GET /api/v1/admin/events/radar`

응답 구조:

- `summary`
  - `total`
  - `actionable`
  - `cooldown`
  - `sell_candidates`
  - `buy_candidates`
- `events`
  - `symbol`
  - `name`
  - `event_type`
  - `event_label`
  - `score`
  - `state`
  - `direction`
  - `occurred_at`
  - `cooldown_until`
  - `cooldown_remaining_sec`
  - `price`
  - `change_rate`
  - `volume_ratio`
  - `reason`

## 스타일 가이드

- `매수 후보`: 청록/에메랄드 계열
- `매도 후보`: 앰버/레드 계열
- `거래량`: 블루 계열
- `쿨다운`: 슬레이트/회색 계열
- 강한 이벤트는 테두리와 점수 배지를 같이 강조

## 운영 지표

이후 버전에서 보면 좋은 지표:

- 이벤트 발생 수
- 액션으로 이어진 비율
- 이벤트 타입별 수익률
- 노이즈로 dismiss된 비율

## 비범위

- 이번 버전에서 이벤트를 DB에 영속 저장하지 않는다.
- 이번 버전에서 복잡한 VWAP/호가 기반 확인 조건은 넣지 않는다.
- 이번 버전에서 전략 로직 자체는 바꾸지 않는다.
