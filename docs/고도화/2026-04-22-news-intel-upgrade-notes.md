# 뉴스 인텔 고도화 메모 (2026-04-22)

## 결론

현재 뉴스 파이프라인은 국내 주식 매매에서 "종목 발굴 엔진"보다 "위험 필터와 시장 맥락 보정"으로 쓰는 것이 맞다.

- `DART`, `KRX`는 국내 개별 종목과 직접 연결되므로 핵심 소스다.
- `YONHAP` 경제 뉴스는 국내 업종/정책/수급 맥락에 유용하다.
- `Bloomberg`, `CNBC`, `Investing`, `Seeking Alpha`는 미국장, 금리, 달러, 유가, AI/반도체 같은 글로벌 위험 분위기 참고용이다.
- `Nasdaq` Markets RSS는 수집은 가능하지만 국내 종목 직접성은 낮아 기본 비활성화가 적절하다.
- 해외 뉴스 번역은 운영 비용/지연 대비 필수성이 낮으므로 기본 비활성화한다. AI 판단에는 원문을 쓰고, 화면 확인이 필요할 때만 번역을 켠다.

## 현재 운영 권장값

| 설정 | 권장 | 이유 |
| --- | --- | --- |
| `NEWS_POLL_ENABLED` | `true` | 뉴스/공시 적재 자체는 유지 |
| `NEWS_DOMESTIC_MEDIA_ENABLED` | `true` | 국내 경제 뉴스 보강 |
| `NEWS_INCLUDE_FOREIGN` | `true` | 글로벌 매크로/섹터 리스크 참고 |
| `NEWS_NASDAQ_ENABLED` | `false` | 직접성 낮고 노이즈 가능성 높음 |
| `NEWS_TRANSLATE_FOREIGN_ENABLED` | `false` | 번역 비용/지연 절감 |
| `NEWS_GATE_ENABLED` | 보수적 유지 또는 shadow 우선 | 성과 검증 전 강한 차단은 위험 |
| `NEWS_SHADOW_ENABLED` | `true` | 뉴스가 실제로 도움이 되는지 검증 |

## 왜 경제/시장 뉴스만으로는 부족한가

현재 소스는 대부분 경제/시장 카테고리다. 따라서 다음 이슈는 시장 매체가 다루면 들어오지만, 정치/정책 일반 뉴스로만 나오면 빠질 수 있다.

- 미국 대통령 발언, 행정명령, 관세 정책
- 대중국 제재, 반도체/AI 수출통제
- 미국 재무부/상무부/백악관 발표
- 한국 정부 산업 정책, 세제, 공매도, 밸류업 정책
- 지정학 이벤트, 방산/원전/에너지 정책

국내 주식에는 이런 정책 이벤트가 실제로 중요하다. 다만 정치/사회 뉴스를 전체 수집하면 노이즈가 커지므로, "정책/매크로 이벤트 레이더"로 좁게 추가하는 방향이 적절하다.

## 고도화 방향

### 1단계: 소스별 가치 측정

뉴스를 더 늘리기 전에 소스별로 실제 가치가 있는지 측정한다.

- source별 신규/중복/실패/stale 비율
- source별 관련 심볼 매핑률
- source별 뉴스 압력과 이후 수익률의 관계
- 뉴스 차단 후보의 forward return
- 뉴스가 없었으면 샀을 후보와 실제 결과 비교

판단 기준:

- `DART`, `KRX`는 기본 유지한다.
- 해외 소스는 "국내 관심 업종 또는 보유/후보 종목과 연결된 기사 비율"이 낮으면 가중치를 낮춘다.
- 특정 소스가 신규성은 높지만 매매 결과와 무관하면 report-only로 낮춘다.

### 2단계: 정책/매크로 이벤트 레이더 추가

일반 정치 뉴스 전체가 아니라 시장 영향이 큰 정책 이벤트만 수집한다.

우선 키워드:

- `tariff`, `trade war`, `China export controls`, `semiconductor sanctions`
- `AI chip`, `advanced chips`, `Treasury`, `Commerce Department`
- `Federal Reserve`, `rates`, `dollar`, `Treasury yields`
- `oil`, `energy sanctions`, `shipping disruption`
- `공매도`, `밸류업`, `세제`, `금투세`, `반도체 지원`, `수출통제`

후보 소스:

- 공식 발표: White House, U.S. Treasury, U.S. Commerce Department, Federal Reserve
- 국내 정책: 기획재정부, 산업통상자원부, 금융위원회, 한국은행
- 보조 뉴스: Reuters 연결 가능성 재검토 또는 안정적인 정책/시장 RSS 대체 소스

운영 원칙:

- 원문 전체를 다 넣지 않고 키워드/주제 필터 통과 기사만 저장한다.
- 처음에는 `POLICY_EVENT` 같은 별도 source/type으로 report-only 적재한다.
- BUY 차단에 바로 연결하지 않고 shadow로만 영향도를 측정한다.

### 3단계: 종목/섹터 연결 강화

해외/정책 뉴스는 개별 국내 종목과 직접 연결되지 않는 경우가 많다. 따라서 "주제 -> 국내 업종/종목군" 매핑이 필요하다.

예시:

| 이벤트 | 국내 연결 |
| --- | --- |
| AI chip demand | 반도체, HBM, 장비, 소재 |
| China export control | 반도체, 디스플레이, 2차전지, 화학 |
| Oil shock | 항공, 운송, 정유, 화학 |
| Strong dollar | 수출주, 원자재 수입주, 외국인 수급 |
| US rate shock | 성장주, 바이오, 인터넷, 코스닥 |
| Defense/geopolitics | 방산, 조선, 에너지 |

필요 작업:

- `topic_relevance` 메타데이터 추가
- `policy_event_type` 분류 추가
- 종목 직접 매칭과 섹터/테마 매칭을 분리
- 뉴스 게이트에서 직접 종목 뉴스와 매크로 뉴스의 가중치를 다르게 적용

### 4단계: 뉴스 게이트를 모드화

뉴스가 실제 수익 개선을 증명하기 전에는 BUY 차단을 강하게 쓰지 않는다.

권장 모드:

- `OFF`: 뉴스 수집/판단 모두 끔
- `POLL_ONLY`: 수집만 하고 매매 판단에는 미사용
- `SHADOW_ONLY`: 매매에는 개입하지 않고 가상의 차단/허용 결과만 기록
- `SEMI_AUTO_GATE_RECOMMENDATION`: 차단 권고만 표시하고 실제 주문은 막지 않음
- `BUY_BLOCK_GATE`: 검증 통과 후 실제 BUY 차단

승급 조건:

- 최소 표본 수 충족
- 뉴스 차단 후보의 forward return이 기준 후보보다 나쁨
- 뉴스 반영 거래의 expectancy/PF가 일반 거래보다 악화되지 않음
- source별 실패율과 stale 비율이 허용 범위 안에 있음

## 구현 우선순위

1. 현재 뉴스는 `POLL_ONLY` 또는 `SHADOW_ONLY`에 가깝게 운용한다.
2. Nasdaq은 기본 off로 둔다.
3. 해외 번역은 off로 둔다.
4. source별 성과 리포트를 먼저 강화한다.
5. 정책/매크로 이벤트 레이더를 별도 타입으로 추가한다.
6. 정책 이벤트는 바로 BUY 차단하지 않고 shadow/report-only로 검증한다.
7. 표본이 쌓이면 source별 가중치와 gate 승급 조건을 조정한다.

## 보류할 것

- 정치/사회 뉴스 전체 수집
- 해외 뉴스 전체 번역
- Nasdaq Markets RSS를 핵심 판단 소스로 승격
- 표본 없이 `NEWS_GATE_ENABLED`를 공격적으로 조정
- LLM이 모든 뉴스를 매번 재분석하는 구조

## 성공 기준

- 뉴스가 차단한 BUY 후보의 이후 수익률이 기준 후보보다 유의하게 낮다.
- 뉴스 반영 거래가 일반 거래보다 expectancy 또는 drawdown 측면에서 개선된다.
- 소스별 유지/제거 판단이 데이터로 가능하다.
- 정책 이벤트가 국내 업종/종목군에 설명 가능한 방식으로 연결된다.
- 장중 지연, 번역 비용, 소스 실패가 매매 루프를 방해하지 않는다.

## 2026-04-23 1차 구현 메모

### 근거

- OpenDART는 주요사항보고서 범주로 전환사채 발행, 소송, 회생절차, 상장폐지 등 경영/재무 영향 이벤트를 구조화해 제공한다.
- KRX는 거래정지를 투자자 보호와 시장 관리를 위한 조치로 설명한다.
- KRX는 불성실공시 법인에 대해 벌점, 매매거래정지, 관리종목 지정, 상장폐지 심사 가능성을 둔다.

따라서 공시/시장공지의 명백한 리스크 이벤트는 LLM 감성 분석을 기다리지 않고 deterministic rule로 `NEGATIVE`와 `impact_score`를 부여하는 편이 적절하다.

### 구현 원칙

- 관심사 분리:
  - `news_risk_classifier`: 공시/시장공지 리스크 감성 분류
  - `news_topic_mapper`: 영문/국문 테마 키워드의 국내 섹터 매핑
  - `news_ingest_service`: 저장 전 두 서비스를 호출해 결과를 메타데이터와 저장 필드에 반영
- TDD:
  - 분류기 단위 테스트를 먼저 작성
  - ingest 통합 테스트로 저장 결과 확인
  - 기존 뉴스 게이트/번역/폴링 테스트 회귀 확인
- 운영 안전:
  - 명시적으로 들어온 `sentiment_label`/`sentiment_score`는 덮어쓰지 않는다.
  - 정치/사회 전체 뉴스를 열지 않고, 고신호 키워드만 섹터 이벤트로 매핑한다.

### 1차 반영 내용

- 거래정지, 상장폐지, 불성실공시, 경영권분쟁 소송, 횡령/배임/감사의견 리스크, 회생/부도, 전환사채/유상증자, 최대주주변경을 리스크 규칙으로 분류한다.
- `AI chip`, `semiconductor`, `export controls`, `Nvidia`, `Micron`, `TSMC`, `ASML` 같은 영문 키워드를 `반도체` 섹터로 연결한다.
- 배터리, 자동차, 인터넷, 방산, 조선 테마도 최소 키워드 기반 매핑을 추가했다.

### 남은 과제

- 기존 DB에 이미 들어간 중립 뉴스는 자동 재분류되지 않는다. 운영 데이터까지 반영하려면 별도 backfill 작업이 필요하다.
- KRX 일반 공지와 국내 경제 뉴스의 종목/섹터 매핑률을 측정해야 한다.
- 리스크 규칙별 실제 차단 후보의 forward return을 쌓아 과차단 여부를 검증해야 한다.
- 정책/매크로 이벤트 전용 source/type은 아직 추가하지 않았다.
