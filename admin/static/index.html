시스템 정보

운영 DB 백업
현재 운영 DB 스냅샷을 `runtime/backups/db` 아래에 저장합니다. 다른 컴퓨터로 옮기기 전이나 초기화 전에 먼저 백업해두세요.
운영 DB 초기화
설정은 유지하고 거래/리포트/활동/뉴스 같은 운영 이력만 비웁니다. 이후 현재 브로커 잔고/보유/미체결을 다시 읽어 새 기준선을 만듭니다.
과거 실현손익/리포트/뉴스 적재 이력은 복구되지 않습니다. 다른 컴퓨터에서 새 기준선으로 다시 시작하거나, 현재 상태만 다시 맞출 때 사용하세요.
